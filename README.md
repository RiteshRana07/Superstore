# Sales Performance Dashboard Project

## Project Overview
This project analyzes retail sales data to identify business insights such as:
- Top-selling products
- Regional sales performance
- Monthly revenue trends
- Profit analysis
- Customer behavior

The project was built using SQL, Python, and Power BI.

---

## Objectives
- Analyze sales and profit trends
- Identify high-performing products
- Detect loss-making products
- Create an interactive dashboard
- Generate business insights from data

---

## Tools & Technologies Used
- Python
- SQL
- Tableau
- pandas
- matplotlib
- MySQL

---

## Dataset Information
Dataset: Superstore Sales Dataset

The dataset contains:
- Orders
- Customers
- Products
- Sales
- Profit
- Region
- Shipping details

Dataset Source:
https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

---

## Project Workflow

### 1. Data Collection
Downloaded the Superstore dataset from Kaggle.

### 2. Data Cleaning
- Removed null values
- Fixed date formats
- Checked duplicate records

### 3. SQL Analysis
Performed:
- Sales analysis
- Profit analysis
- Aggregations
- Grouping
- Trend analysis

### 4. Python Analysis
Used pandas and matplotlib for:
- Data manipulation
- Visualization
- Trend analysis

### 5. Dashboard Creation
Built an interactive dashboard in Tableau.

---

## Key Insights
- Technology category generated the highest sales.
- West region had the highest profit.
- Sales increased significantly during year-end months.
